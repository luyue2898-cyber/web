Overview of Web Programming

Basic Purpose of the Web

The basic purpose of the Web is to allow documents created on one computer to be easily viewed on another computer.

Why is it called Web?

Computers around the world are connected like a spider web via the Internet. The system that enables easy exchange of web documents is called WWW (World Wide Web), or simply Web.

Three Components of a Web Page
  • HTML - Document structure and content
  • CSS(Cascading Style Sheet) - Document appearance
  • Javascript - Behaviors and application programs
